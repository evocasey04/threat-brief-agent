### 3. NGINX "nginx2root" HTTP/2 RCE

**Severity:** critical

The decade‑old CVE‑2026‑123007 allows unauthenticated code execution on any NGINX server with HTTP/2 enabled, and can be chained with a kernel bug to obtain root. Given NGINX's ubiquity as a front‑end web server, exploitation can compromise countless web applications.

**Do this:** Disable HTTP/2 in NGINX or upgrade to a version that patches CVE‑2026‑123007; verify the change with a security scan.
