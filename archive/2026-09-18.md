### 1. Check Point Management Server remote code execution

### 2. Unbound DNSSEC validator heap overflow

**Severity:** critical

A heap overflow in Unbound's DNSSEC validator allows remote code execution when a resolver processes a maliciously crafted DNS zone. As Unbound is widely deployed in recursive resolvers, exploitation can lead to widespread compromise of DNS infrastructure and traffic redirection.

**Do this:** Upgrade Unbound to version 1.26.1 or later and block recursive queries to zones that you do not authoritatively control.

- [The Hacker News](https://thehackernews.com/2026/09/critical-unbound-dnssec-validator-flaw.html)

### 3. Docker Sandbox macOS host file escape

**Severity:** critical

Malicious code inside a Docker container on macOS can break out of the shared project directory and read or modify any file on the host with the host account’s privileges. This defeats container isolation and can expose sensitive user data or system credentials.

**Do this:** Update Docker to the latest release, avoid mounting host directories into containers unless necessary, and enforce least‑privilege file system permissions on the host.

- [The Hacker News](https://thehackernews.com/2026/09/critical-docker-sandboxes-flaw-lets.html)

### 4. Brevo supply‑chain attack via stolen Cloudflare API key

**Severity:** high

Attackers exfiltrated a Cloudflare API key and injected malicious ClickFix scripts into Brevo’s web assets and customer sites, turning legitimate traffic into a malware distribution vector. The compromise can affect all Brevo customers and any downstream sites that embed its scripts.

**Do this:** Revoke the compromised Cloudflare API key, generate a new one, and audit all injected scripts; implement Subresource Integrity (SRI) for third‑party JavaScript.

- [BleepingComputer](https://www.bleepingcomputer.com/news/security/brevo-supply-chain-attack-injected-clickfix-scripts-on-customer-sites/)

### 5. npm package stealer campaigns (WeaselBiscuit & PhantomRaven)

**Severity:** high

Thirteen malicious npm packages have been used to deliver JavaScript stealer families that harvest Chrome extension storage and other credentials from developers’ environments. Widespread use of these packages can lead to large‑scale credential theft across the software supply chain.

**Do this:** Run `npm audit` and remove any of the identified malicious packages; lock dependencies with a vetted `package-lock.json` and monitor for new suspicious packages.
